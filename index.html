How it works

  1. 1

    Pick the unit

    Choose an example point or drop a pin on any storefront. Add the asking rent if you have it.

  2. 2

    Watch the agent ask Qloo

    Each lookup appears as it happens: what it asked, what came back, which tag it chose. About 20 calls, a few minutes.

  3. 3

    Take the memo to the meeting

    A one-page shortlist with a GO, ADJUST or NO-GO call per concept, the evidence behind it and the limits. Prints cleanly.

What it does not know

Qloo describes the aggregate taste of an area's audience, not foot traffic, sales or any person. Scores rank the candidates in one run against each other. Nearby supply counts OpenStreetMap venues, which can be incomplete. Rent ceilings come from a survival model built on official data, calibrated for Paris and Chicago only. Alcohol-led concepts are left out.
